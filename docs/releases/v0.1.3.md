This patch release makes the blacked-out screen reachable again without the wall
switch.

## Highlights

- Tap-to-wake: while ambient-light blackout is active, any touch lights the display at
  low brightness for twenty seconds, and every further touch refills that window.
- The window opens before the touch reaches the clock view, so a single uninterrupted
  right swipe out of blackout still opens the device controls and the ceiling light.
- The window only suppresses blackout locally. Ambient light keeps deciding the real
  state, so turning the room light on hands the display back to normal visibility, and
  doing nothing returns it to pure black.
- Ending a bedtime reminder with `DONE` or `+15 MIN` still blacks the screen out
  immediately instead of lingering for the tap-to-wake window.

## Also included

Version 0.1.2 was a local build that was never published, so upgrading from v0.1.1
also picks up its two fixes:

- Recovering the Yeelight address by MAC never actually worked. The resolver runs
  `ip neigh show dev wlan0`, and naming the device makes `ip` drop the `dev wlan0`
  pair from every line, leaving four fields instead of six. The parser required at
  least five and therefore skipped every entry, silently falling back to the stale
  configured address on every attempt. A non-zero exit left no trace in the log either.
- The twelve major dial ticks are aligned on a single inner ring.

## Compatibility

- Android 10 or newer
- ARM64 devices only (`arm64-v8a`)
- Tested on a rooted Xiaomi Mi 9 Pro 5G running Android 10 / MIUI 12
- No new permission, sensor, or root requirement

## Installation note

Download and install `Desktop-Standby-Clock-v0.1.3.apk` below. It is signed with the
same public release key as earlier releases and can update them directly. A locally
built debug version uses a different signature and must be uninstalled first;
uninstalling clears saved app settings.

The accompanying `.sha256` file can be used to verify download integrity.

此补丁版本解决了一个日常痛点：房间黑下来以后屏幕全黑，碰它没有任何反应，只能先去按
墙上的实体开关把灯打开，等环境光把屏幕唤醒。

- 轻触点亮：熄屏状态下碰一下屏幕，就以低亮度亮起 20 秒；期间再碰一下重新计满。
- 点亮发生在触摸事件到达时钟视图之前，所以摸黑回家不用先点一下再划——一次右滑就能
  直接划进设备控制去开吸顶灯。
- 这个窗口只是临时压住熄屏，环境光状态机仍然说了算：真把灯打开了，屏幕会自然过渡到
  常亮；没人再碰就在 20 秒后黑回去。
- 睡眠提醒里点 `DONE` 或 `+15 MIN` 依然立刻黑屏，不会被点亮窗口拖着多亮 20 秒。

0.1.2 只是一个未曾发布的本地构建，所以从 v0.1.1 升级过来还会一并获得它的两个修复：

- 按 MAC 恢复吸顶灯地址其实从来没成功过。解析器执行的是 `ip neigh show dev wlan0`，
  而命令里点名了设备之后，`ip` 就不再输出 `dev wlan0` 这一对，每行只剩四个字段而不是
  六个；解析要求至少五个字段，于是每一行都被跳过，每次都静默回退到配置里那个可能已经
  过期的地址，命令非零退出时日志里也不留痕迹。
- 表盘的十二个大刻度对齐到同一条内圈。

当前版本仅打包 `arm64-v8a`，要求 Android 10 或更高版本，没有新增任何权限、传感器或
root 依赖。正式版使用与既往版本相同的发布密钥，可以直接覆盖升级；本地 debug 版签名
不同，安装正式版前仍需卸载。
