This is the first public preview of Desktop Standby Clock, a native fullscreen
Android clock designed to turn a spare landscape phone into a dedicated desktop
display.

## Highlights

- Two clock faces: a P3 amber phosphor dial and a calligraphic digital display
- Hourly automatic face rotation and manual swipe switching
- Ambient-light blackout with hysteresis for OLED displays
- Five-minute pixel shifting to reduce burn-in risk
- Persistent bedtime reminder with a short CRT-style chime
- Local Yeelight control and Wake-on-LAN
- Optional rooted-MIUI boot and task-recovery support

## Compatibility

- Android 10 or newer
- ARM64 devices only (`arm64-v8a`)
- Tested on a rooted Xiaomi Mi 9 Pro 5G running Android 10 / MIUI 12
- Root is optional for the clock UI; it is only used for dedicated-device
  persistence features

## Installation note

Download and install `Desktop-Standby-Clock-v0.1.0.apk` below. If a locally
built debug version is already installed, uninstall it first because the public
release uses a different signing key. Uninstalling clears the app's saved
settings.

The accompanying `.sha256` file can be used to verify download integrity.
