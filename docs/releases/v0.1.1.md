This patch release makes the dedicated clock more resilient and adds a private
traffic-status dashboard.

## Highlights

- Yeelight control now identifies the configured ceiling light by its stable MAC
  address and automatically recovers when DHCP changes the light's IP address.
- A new traffic dashboard reads HostVDS and subscription usage from the optional
  private VPS bridge without storing provider credentials on the phone.
- Device-control failures preserve the clock experience and expose clearer offline
  states instead of interrupting the main display.
- Dedicated-device maintenance gained a battery guardian for rooted Xiaomi hardware,
  along with expanded operational documentation and regression coverage.

## Compatibility

- Android 10 or newer
- ARM64 devices only (`arm64-v8a`)
- Tested on a rooted Xiaomi Mi 9 Pro 5G running Android 10 / MIUI 12
- Root remains optional for the clock itself; MAC-based Yeelight address recovery and
  dedicated-device persistence use root on the configured phone

## Installation note

Download and install `Desktop-Standby-Clock-v0.1.1.apk` below. It is signed with the
same public release key as v0.1.0 and can update that release directly. A locally built
debug version uses a different signature and must be uninstalled first; uninstalling
clears saved app settings.

The accompanying `.sha256` file can be used to verify download integrity.
