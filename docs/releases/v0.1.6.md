This release adds two lighting presets and a sedentary reminder, and fixes a
ceiling light toggle that reported failure even when it had worked.

## Highlights

- The ceiling light button in the device panel now has two presets along its
  bottom edge. STUDY sets 4000 K at full brightness; REST sets 2700 K at 25
  percent. Either one turns the lamp on if it is off. The rest of the button still
  toggles power.
- Toggling the ceiling light no longer shows OFFLINE after a successful switch. The
  lamp pushes a state notification before its reply, and the client used to read
  that notification as the reply. It now waits for the reply with its own request id.
- A sedentary reminder prompts a stand-up break at a set interval (45 minutes by
  default, 15 to 120) within a working window that starts at a chosen time and ends
  at bedtime.
- Clock settings are now split into CLOCK and REMINDERS tabs.
- Version 0.1.5 was never published; this release follows v0.1.4 directly.

## Compatibility

- Android 10 or newer
- ARM64 devices only (`arm64-v8a`)
- Tested on a rooted Xiaomi Mi 9 Pro 5G running Android 13 (TrebleDroid vanilla GSI)
  with a Yeelight ceil26 ceiling light
- No new permission, sensor, or root requirement

## Installation note

Download and install `Desktop-Standby-Clock-v0.1.6.apk` below. It is signed with the
same public release key as earlier releases and can update them directly. A locally
built debug version uses a different signature and must be uninstalled first;
uninstalling clears saved app settings.

The accompanying `.sha256` file can be used to verify download integrity.

此版本新增两个灯光预设和久坐提醒，并修复了吸顶灯开关明明成功却报失败的问题。

- 设备面板里吸顶灯按钮的底部新增两个预设：STUDY（学习）为 4000K、全亮；REST（休息）
  为 2700K、25% 亮度。灯关着时点预设会直接打开。按钮其余区域仍是开关。
- 吸顶灯开关成功后不再显示 OFFLINE。灯在回执之前会先推一条状态通知，旧版把这条通知
  当成了回执；现在会一直读到带有本次请求 id 的那一行。
- 新增久坐提醒：在工作时段内（从设定时间开始，到就寝时间结束）按间隔提醒起身活动，
  默认 45 分钟，可在 15 至 120 分钟之间调节。
- 时钟设置拆分为 CLOCK 和 REMINDERS 两个页签。
- 0.1.5 从未发布，本版直接接在 v0.1.4 之后。

当前版本仅打包 `arm64-v8a`，要求 Android 10 或更高版本，没有新增任何权限、传感器或
root 依赖。
